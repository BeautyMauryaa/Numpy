# NumPy Practice

A collection of Jupyter notebooks for learning NumPy arrays and common array operations.

## Topics covered

The notebooks include array access, data types, copying versus views, filtering, iteration, and joining arrays.

## Run the notebooks

Requires Python 3 and Jupyter Notebook or JupyterLab.

```bash
python -m venv .venv
```

Activate the environment:

**Windows PowerShell**
```powershell
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

Install the tools:

```bash
python -m pip install numpy notebook
jupyter notebook
```

Open the notebooks in the `Numpy/` folder and run the cells in order.
